# SHRUNK — Tabletop Racing V1
Standalone merge-ready prototype. Landscape iPhone controls: left thumb hold GAS, slide up on GAS for BOOST, right thumb steer. Two-lap tabletop circuit, checkpoint order, timer, local best, fall-off/stuck recovery. Ordinary tabletop props establish scale. No Rollies/Arcade branding, wallet, Passport, multiplayer, or production dependency.

Run: `npm test` then `npm run check`.
