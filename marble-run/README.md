# SHRUNK — Marble Run V1 Prototype

Standalone merge-ready SHRUNK Tabletop World module. One-thumb landscape marble run: drop the marble, drag left/right to guide it through a giant tabletop course, pass four checkpoints, avoid/bank off desk props, reach the finish before the 45-second timer, score speed/checkpoint bonuses, save personal best, replay instantly.

V1 intentionally uses a bare marble rather than a vehicle shell so the rolling/control language can be validated first. Designed to accept the existing SHRUNK 25 mm marble vehicle concept later without changing the core run loop.

No wallet or Passport dependency. No changes to live Fingerboard Sessions.

Run `npm test` and `npm run check`.
