# SHRUNK — Desk Shot V1 prototype

Standalone merge-ready prototype for SHRUNK Tabletop World V1. It does not modify the live Fingerboard Sessions source.

## Loop
- Landscape mobile-first, one-thumb pointer control
- 5 shots per round
- Drag backward from puck to set aim/power; release to shoot
- Wall/tape-roll rebounds count as banks
- Targets: 25 / 50 / 100
- 1 bank = 1.5x, 2+ banks = 2x, hard shot can add +0.25x
- Round result + local personal best + instant replay
- Pause/restart included

## Merge note
This prototype intentionally uses the existing SHRUNK visual language (wordmark treatment, acid accent, compact HUD, landscape safe-area approach) but is isolated so Work can merge it later without touching the current fingerboard game until approved.
