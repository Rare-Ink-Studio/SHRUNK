# SHRUNK V8 — THE INFINITE LOOP · DAILY ALIVE PASS

This pass deepens the return-every-day layer without changing the real reward economy.

## Daily challenge variety
- Expanded the rotation from 7 recurring weekday sets to 14 deterministic daily sets.
- Different dates now push players toward different games, scores, clean runs, grinds, banks, boosts and time targets.
- Three challenges still appear per day.
- Completed challenges still cannot be farmed for repeat coins.

## Celebrations
Gameplay now surfaces milestone-specific celebration states:
- DAILY CHALLENGE COMPLETE
- TODAY'S SESSION COMPLETE
- WORLD TOUR COMPLETE
- TICKET READY
- PERFECT WEEK

These remain local/test progression states. No real One Home Ticket or Dood Coin transfer occurs.

## Home progression presentation
- 7-day week participation dots.
- WORLD TOUR game completion chips.
- Dynamic NEXT MOVE card pointing to the next unfinished Daily Challenge.
- Dedicated messaging for Today Complete, Ticket Ready and Perfect Week.
- Existing coin, daily-session, streak and weekly requirements remain visible.

## Economy/testing rules preserved
- 3 test SHRUNK Coins per Daily Challenge.
- +3 Daily Session completion bonus.
- +4 WORLD TOUR completion bonus.
- Ticket Ready requires 64 weekly Coins + 5 Daily Sessions + WORLD TOUR.
- 88 Coins + 7 days + WORLD TOUR = Perfect Week.
- These are development values, not a finalized economy.
